# Shazam Music Identification System

A Python implementation of a music identification system based on the Shazam algorithm described in "An Industrial Strength Audio Search Algorithm" by Avery Li-Chun Wang.

## Overview

This project implements the core audio fingerprinting and matching techniques used by Shazam and similar music identification services. The system can identify songs from short audio samples by creating acoustic fingerprints and matching them against a database of known songs.

## Algorithm Overview

The system follows these key steps:

1. **Spectrogram Generation**: Convert audio signals to time-frequency representations using Time-Dependent Fourier Transform (TDFT)
2. **Peak Picking**: Identify local maxima in the spectrogram that are robust to noise and distortion
3. **Fingerprint Generation**: Create hashes from peak constellations (anchor points with their neighbors)
4. **Database Construction**: Store fingerprints in a searchable database
5. **Matching**: Compare sample fingerprints against the database using time-pair matching

## Usage

### Basic Song Identification (main.py)

1. Build a database from song files:
   ```bash
   python main.py song1.wav song2.wav song3.wav
   ```

2. The program will prompt for an audio sample to identify
3. Results include:
   - Spectrograms with selected peaks
   - Match scores for each song
   - Visual identification results

### Similarity Matrix Calculation (main2.py)

Calculate similarity between songs in a database:
```bash
python main2.py song1.wav song2.wav song3.wav
```
This generates `result.csv` containing the similarity matrix.

### Similarity Analysis

Analyze the similarity matrix:
```bash
python sim_mat_analysis.py
```

### Audio Conversion

Convert MP4 files to WAV format:
```bash
chmod +x util/mp4_to_wav.sh
./util/mp4_to_wav.sh input.mp4
```

## Key Parameters

### TDFT Parameters (in main.py/main2.py)
- `windowsize = 0.008` (8ms window)
- `windowshift = 0.004` (4ms shift)
- `fftsize = 1024` (FFT size)

### Peak Picking Parameters
- `f_dim1 = 30`, `t_dim1 = 80` (first pass window dimensions)
- `f_dim2 = 10`, `t_dim2 = 20` (second pass window dimensions)
- `percentile = 70` (threshold percentile)
- `base = 8` (minimum frequency bin, ~320Hz)
- `top = 375` (maximum frequency bin, ~15kHz)

### Hash Parameters
- `delay_time = 50` (0.2s delay for anchor-neighbor pairs)
- `delta_time = 150` (0.6s maximum time difference)
- `delta_freq = 12` (~516Hz maximum frequency difference)

## Test Results

The system was tested with 5 popular songs (30-second clips at 8000kHz):

1. "Rolling in the Deep" by Adele
2. "Buffalo Soldier" by Bob Marley
3. "In Da Club" by 50 Cent
4. "Living on a Prayer" by Bon Jovi
5. "Summer of 69" by Bryan Adams

### Key Findings:
- **Full-length identical samples**: Successfully identified with high confidence
- **Degraded 15-17 second clips**: Mixed results depending on noise levels
  - "Summer of 69": Identified despite background noise (voices, paper crinkling, finger snapping)
  - "Rolling in the Deep": Identified with table thumping noise
  - "In Da Club": Failed identification with significant noise interference

## Implementation Details

### fingerprint.py
- `hashPeaks()`: Creates fingerprint hashes from peak lists
- `hashSamplePeaks()`: Creates hashes for query samples
- `findTimePairs()`: Matches sample hashes against database
- `findTimePairs2()`: Computes song-to-song similarities

### peakpicker.py
- `find_thres()`: Calculates adaptive threshold for peak detection
- `peak_pick()`: Identifies local maxima in spectrograms
- `reduce_peaks()`: Filters peaks by frequency-dependent thresholds

### tdft.py
- `tdft()`: Computes spectrograms using Hamming window and FFT

## Limitations

1. **Python 2.7**: Code is written for Python 2.7 and may require modification for Python 3
2. **Audio Format**: Currently supports WAV files; MP4 files require conversion
3. **Performance**: Matching algorithm uses brute-force search; could be optimized with indexing
4. **Robustness**: Performance degrades with significant noise and compression artifacts
